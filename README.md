# Deadlock Board

A match timer and tactics board for Deadlock. Open it here:
https://chandleracolvin.github.io/deadlock-board/

Works best in Chrome or Edge on a computer. Click the page once so it can play alert sounds. Your settings and
edits are saved in your own browser.

Unofficial fan-made tool, not affiliated with or endorsed by Valve. Marker positions come from metabot.gg's
datamined map; heavy crates, steam vents and camp names from POSHYPOP's Deadlock maps (poshypop.com/resources);
timings from the game data on deadlock.wiki and the official patch notes.
